# Diagram sources
- `system_architecture.dot` and `agent_flowchart.dot` are editable [Graphviz DOT](https://graphviz.org/doc/info/lang.html) sources.
- SVG files are rendered output. To regenerate: `dot -Tsvg system_architecture.dot -o system_architecture.svg`.
- Flowchart includes a clarification/exception branch to satisfy the proposal rubric.
